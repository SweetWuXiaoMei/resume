# 可观测性体系设计 —— 架构师级面试准备

> 基于天天拍车高并发竞拍系统的真实场景，从架构师视角设计完整的可观测性体系。
> 零基础友好：每个概念都从"是什么 → 为什么 → 怎么做"递进讲解。

## 为什么要学可观测性？

架构师面试中，可观测性是**差距题**——多数候选人只会说"我们用过 Prometheus + Grafana"，但架构师需要讲清楚：

- 怎么设计指标体系让业务方和运维都能看懂？
- 日志、指标、链路追踪三者怎么串联？
- 10 万 QPS 下采样策略怎么定？
- 告警怎么避免"狼来了"？
- 这套体系花了多少钱？ROI 怎么算？
